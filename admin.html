Импорт / Экспорт Excel

Экспорт меню

Скачать все категории и товары в Excel файл с выпадающими списками для удобного редактирования.

Импорт меню

Загрузите отредактированный Excel файл. Товары сопоставляются по названию:

  • Название есть в файле и в БД → обновить
  • Название только в файле → добавить
  • Название только в БД → удалить

Генерация ценников

Загрузите Excel файл меню — будут сгенерированы ценники для товаров, у которых "Нужен ценник" = да.

Меню напитков (A4)

Скачайте шаблон, отредактируйте напитки и цены, затем загрузите для генерации меню.
